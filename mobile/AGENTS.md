# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Pinned to SDK 54 (not the latest) because the team's physical test devices
only have Expo Go 54.0.8 installed — Expo Go supports at most the current +
previous SDK, so anything newer breaks "scan the QR code" testing on those
devices. Don't bump past SDK 54 without confirming Expo Go on the actual
test devices supports it first.
